
# FF7 Ultima – Independent Fork

A real-time game editor and toolkit for Final Fantasy VII PC.

This is an independently maintained fork of the original FF7 Ultima project, featuring expanded speedrunning tools, encounter RNG visualisation, enhanced save states and additional gameplay options.

Currently supports the English Steam version of Final Fantasy VII.

[Screenshot](https://raw.githubusercontent.com/maciej-trebacz/ff7-ultima/main/ultima-1.8-screenshot.png)

## Having issues? Want other features?

You can report bugs, request features and provide feedback through the [Issues](https://github.com/themattdavis/ff7-ultima/issues) tab.

## Current features

- **Game information:** Display and edit game information, including Gil, GP, disc, battle statistics and in-game time.
- **Speedrun module:** Real-time IGT, field manipulation, step and encounter RNG editing, Step Lock, elevator manipulation and battle editing.
- **Stepgraph:** Visual encounter-step progression, encounter prediction, player position tracking, configurable graph settings and standalone window support.
- **Field module:** Field ID and step information, model editing, field warping, encounter selection and dialogue skipping.
- **World module:** World-map viewer, model editing, teleportation, encounter information, camera controls and walk/land anywhere.
- **World-map debugging:** Triangle numbering, chunk slot visualisation, player hitboxes, geometry inspection and model alignment tools.
- **Expanded save states:** Field, snowboard and world-map save states, with position and RNG restoration, importing/exporting, categorisation, bulk management and keyboard navigation.
- **Battle module:** Battle information, invincibility, instant ATB, EXP/AP/Gil multipliers, character and enemy editing, instant kill and battle logging.
- **Party module:** View and edit character stats, equipment and status flags.
- **Chocobo module:** Manage stables and chocobos, including their statistics.
- **Gameplay hacks:** Auto-skip FMVs, save anywhere, no Glacier freeze, no Whirlwind Maze battles, Skip CPR and Double Input Fix.
- **Global hotkeys:** Configurable shortcuts for game manipulation, save-state navigation and application controls.
- **Automatic updates:** Integrated updater with signed update verification.
